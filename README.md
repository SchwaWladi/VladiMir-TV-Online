# ВладиМир TV Онлайн · 3.0.0

Это отдельное приложение для Android TV / Fire TV. У него собственный application ID `com.vladimirtv.online`, поэтому оно устанавливается рядом со старым ВладиМир TV и не перезаписывает его.

## Что реализовано в этой версии

- Цветной интерфейс, отдельная отметка «Онлайн», главный экран с беззвучным превью последнего канала и индикатором входящего сетевого трафика.
- ТВ и видеоплейлисты, Xtream Codes и подключение видеопортала. Видеотека обновляется при запуске и возвращении в приложение; период обновления настраивается.
- XMLTV EPG: выбор нескольких источников, включая EPG из M3U, пользовательский XMLTV, Xtream, FreeEPG для Германии и России, а также альтернативные и дополнительные немецкие ленты; настраиваемая частота, сопоставление каналов, нормализация названий и длина периода программы/архива.
- Определение распространённых атрибутов catch-up в M3U и выбор резервного формата архива.
- Отдельный экран Stalker / Ministra: имя портала, URL, MAC, при необходимости логин и пароль, проверка профиля, категории, каналы и запуск потока. Индикатор становится зелёным после успешной проверки токена и профиля.
- В настройках плеера общий буфер IPTV и видеотеки на 15, 30, 60, 75, 120 секунд или 5 минут. Пять минут — верхний предел; фактический буфер зависит от битрейта и памяти Fire TV, а настройка применяется после перезапуска приложения.
- Дополнительные XMLTV-адреса можно добавлять и менять, сохраняя остальные источники; их включают галочками в списке EPG. Отчёт после загрузки показывает домены источников и ошибки ответов.
- Видеотека с выбором встроенного или внешнего плеера, поиском и фильтром по году, если год присутствует в данных источника.
- Раздел модулей, настройки плеера, системные ссылки на настройки Wi-Fi и времени, необязательный запуск при старте устройства, Picture-in-Picture и DLNA-поиск.
- Бесплатный каталог интернет-радиостанций по Германии и России, а также анимированная локальная заставка «Камин».
- Отдельный пункт «Музыка» слева: поиск музыкальных интернет-станций по названию и выбор по жанрам. Используются открытые эфиры Radio Browser; скачивания отдельных песен нет.
- Пункт YouTube слева открывает установленное приложение YouTube, а если его нет — веб-версию. Вход через Google выполняется только на официальном YouTube экране; плеер не запрашивает и не хранит пароль.
- Русский, немецкий и английский интерфейсы.

## Важные ограничения

Stalker не имеет единого способа авторизации, одинакового для всех провайдеров. Проверка и загрузка каналов используют стандартный API Stalker/Ministra и зарегистрированный у провайдера MAC-адрес. Варианты входа по логину и паролю включены для порталов, где провайдер настроил соответствующий сценарий; они требуют HTTPS. Если провайдер использует собственный API, нестандартный путь или другую авторизацию, такой портал может потребовать отдельной адаптации. Зелёный статус означает, что портал выдал токен и профиль, но не гарантирует, что подписка включает каждый канал.

Архив доступен только если сам поставщик потока его предоставляет и M3U содержит нужные параметры или известен совместимый формат URL. EPG не создаёт архив: телегид и catch-up — независимые возможности источника. Внешние бесплатные XMLTV-ленты могут временно менять адрес или быть недоступны; если выбранная лента не подходит, отключи её и оставь рабочие источники провайдера.

## Сборка APK

1. Создай новый пустой репозиторий `VladiMir-TV-Online` и загрузи в его корень содержимое архива.
2. В GitHub Actions добавь secret `ANDROID_DEBUG_KEYSTORE_B64` с постоянным Android keystore. Для установки поверх будущих версий нужен тот же ключ.
3. Запусти workflow **Build ВладиМир TV Онлайн APK**. APK появится в Artifacts.
4. Для проверки установки рядом со старым приложением достаточно установить APK с новым ID `com.vladimirtv.online`.

Для проверки обновления из самого приложения создай GitHub Release с новой версией в репозитории `SchwaWladi/VladiMir-TV-Online` и приложи APK. Для другого имени аккаунта или репозитория нужно изменить адрес обновлений в исходном коде. Эта сборка имеет версию `3.0.0` и код `4`, чтобы обновляться поверх версии 2.0.1 при той же подписи APK.

## Телефон и VPortal

Локальный relay находится в `relay/server.mjs`. Его запускают за HTTPS-прокси с публичным `PUBLIC_ORIGIN`; по умолчанию сервер слушает `127.0.0.1:8080`. На телевизоре выбери подключение с телефона и подтверди передачу источника.
